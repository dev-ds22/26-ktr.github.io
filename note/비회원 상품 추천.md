## 참고 - OG Tag
### 1. Meta Tag의 사용 위치

`og:title`, `og:description`은 HTML 문서의 `<head>` 영역에 작성하는 **Open Graph Meta Tag**입니다.

```html
<head>
  <title>상품 상세 - buyKOREA</title>
  <meta name="description" content="상품 상세 페이지 설명">
  <meta property="og:title" content="프리미엄 한국 상품">
  <meta property="og:description" content="전 세계 바이어를 위한 한국 우수 상품 정보">
  <meta property="og:image" content="https://www.example.com/images/product.jpg">
  <meta property="og:url" content="https://www.example.com/products/10001">
  <meta property="og:type" content="product">
</head>
```

### 2. 어디에서 사용하는가?

|사용 주체|사용 목적|예시|
|---|---|---|
|Facebook, LinkedIn, KakaoTalk, Slack, Teams 등|URL 공유 시 미리보기 카드 생성|제목, 설명, 이미지 표시|
|검색엔진 크롤러|페이지 의미 파악 보조|검색 노출 정보 참고 가능|
|커머스/콘텐츠 크롤러|상품·콘텐츠 요약 정보 수집|상품명, 설명, 대표 이미지|
|내부 시스템|URL Preview, 상품 링크 미리보기 생성|관리자/BO 화면에서 링크 카드 표시|
|SEO/마케팅 도구|공유 최적화 상태 점검|OG 누락 여부 검사|

### 3. 일반 Meta Tag와 OG Meta Tag 차이

|구분|태그|주 사용 목적|
|---|---|---|
|HTML 기본 제목|`<title>`|브라우저 탭, 검색엔진 기본 제목|
|HTML 기본 설명|`<meta name="description">`|검색엔진 결과 설명 후보|
|Open Graph 제목|`<meta property="og:title">`|SNS/메신저 공유 제목|
|Open Graph 설명|`<meta property="og:description">`|SNS/메신저 공유 설명|
|Open Graph 이미지|`<meta property="og:image">`|공유 카드 대표 이미지|

### 4. 커머스 시스템에서의 사용 예

상품 상세 페이지라면 서버에서 상품 정보를 조회한 뒤 HTML `<head>`에 동적으로 출력합니다.

```html
<meta property="og:title" content="${goods.goodsName}">
<meta property="og:description" content="${goods.summary}">
<meta property="og:image" content="${goods.mainImageUrl}">
<meta property="og:url" content="https://www.example.com/goods/${goods.goodsId}">
<meta property="og:type" content="product">
```

Spring MVC + JSP 기준 예시:

```jsp
<title>${goods.goodsName}</title>
<meta name="description" content="${goods.summary}">
<meta property="og:title" content="${goods.goodsName}">
<meta property="og:description" content="${goods.summary}">
<meta property="og:image" content="${goods.mainImageUrl}">
<meta property="og:url" content="${canonicalUrl}">
```

중요한 점은 **SNS/메신저 크롤러는 JavaScript 실행을 제대로 하지 않는 경우가 많기 때문에 OG 태그는 SSR 방식으로 최초 HTML 응답에 포함하는 것이 안전**합니다.

### 5. 브라우저 JavaScript에서 취득하는 방법

현재 페이지의 Meta Tag를 읽는 경우:

```javascript
const ogTitle = document.querySelector('meta[property="og:title"]')?.getAttribute('content');
const ogDescription = document.querySelector('meta[property="og:description"]')?.getAttribute('content');
const description = document.querySelector('meta[name="description"]')?.getAttribute('content');
console.log(ogTitle);
console.log(ogDescription);
console.log(description);
```

공통 함수:

```javascript
function getMetaContent(selector) {
  return document.querySelector(selector)?.getAttribute('content') || '';
}
const meta = {
  title: getMetaContent('meta[property="og:title"]'),
  description: getMetaContent('meta[property="og:description"]'),
  image: getMetaContent('meta[property="og:image"]'),
  url: getMetaContent('meta[property="og:url"]')
};
```

단, 브라우저에서 **다른 도메인의 HTML을 직접 fetch해서 Meta Tag를 읽는 것은 CORS 정책 때문에 실패할 수 있습니다.** 외부 URL의 OG 정보를 읽으려면 서버에서 수집하는 방식이 일반적입니다.

### 6. Java/Spring 서버에서 외부 URL의 Meta Tag 취득 방법

가장 간단한 방법은 `Jsoup`을 사용하는 것입니다.

#### Maven dependency

```xml
<dependency>
  <groupId>org.jsoup</groupId>
  <artifactId>jsoup</artifactId>
  <version>1.17.2</version>
</dependency>
```

#### Java 예제

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
public class MetaTagReader {
    public static void main(String[] args) throws Exception {
        String url = "https://www.example.com/products/10001";
        Document doc = Jsoup.connect(url)
                .userAgent("Mozilla/5.0")
                .timeout(5000)
                .get();
        String title = getMetaContent(doc, "meta[property=og:title]");
        String description = getMetaContent(doc, "meta[property=og:description]");
        String image = getMetaContent(doc, "meta[property=og:image]");
        String normalDescription = getMetaContent(doc, "meta[name=description]");
        if (title.isEmpty()) {
            title = doc.title();
        }
        if (description.isEmpty()) {
            description = normalDescription;
        }
        System.out.println("title = " + title);
        System.out.println("description = " + description);
        System.out.println("image = " + image);
    }
    private static String getMetaContent(Document doc, String cssQuery) {
        Element element = doc.selectFirst(cssQuery);
        return element != null ? element.attr("content") : "";
    }
}
```

### 7. Spring Service 예제

```java
import lombok.Data;
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.springframework.stereotype.Service;
@Service
public class OgMetaService {
    public OgMetaInfo readOgMeta(String url) {
        try {
            Document doc = Jsoup.connect(url)
                    .userAgent("Mozilla/5.0")
                    .timeout(5000)
                    .followRedirects(true)
                    .get();
            OgMetaInfo result = new OgMetaInfo();
            result.setTitle(firstNonEmpty(
                    meta(doc, "meta[property=og:title]"),
                    doc.title()
            ));
            result.setDescription(firstNonEmpty(
                    meta(doc, "meta[property=og:description]"),
                    meta(doc, "meta[name=description]")
            ));
            result.setImage(meta(doc, "meta[property=og:image]"));
            result.setUrl(firstNonEmpty(
                    meta(doc, "meta[property=og:url]"),
                    url
            ));
            return result;
        } catch (Exception e) {
            throw new IllegalStateException("Meta tag read failed. url=" + url, e);
        }
    }
    private String meta(Document doc, String selector) {
        Element element = doc.selectFirst(selector);
        return element != null ? element.attr("content") : "";
    }
    private String firstNonEmpty(String... values) {
        for (String value : values) {
            if (value != null && !value.trim().isEmpty()) {
                return value.trim();
            }
        }
        return "";
    }
    @Data
    public static class OgMetaInfo {
        private String title;
        private String description;
        private String image;
        private String url;
    }
}
```

### 8. Controller 예제

```java
import lombok.RequiredArgsConstructor;

import org.springframework.web.bind.annotation.RequestParam;
```

### 9. 실무 적용 시 주의사항

|항목|주의사항|
|---|---|
|SSR 필요성|SNS 크롤러 대응을 위해 OG 태그는 최초 HTML에 포함 권장|
|JavaScript 렌더링|JS로 나중에 삽입한 OG 태그는 크롤러가 못 읽을 수 있음|
|CORS|브라우저에서 외부 URL 메타 수집은 CORS로 제한 가능|
|이미지 URL|`og:image`는 절대경로 권장|
|캐시|SNS/메신저는 OG 정보를 캐시하므로 수정 후 즉시 반영 안 될 수 있음|
|Redirect|크롤링 시 `followRedirects=true` 권장|
|Timeout|외부 URL 수집은 timeout 필수|
|보안|URL 파라미터 기반 수집 API는 SSRF 방어 필요|

### 10. 보안상 중요한 부분: SSRF 방어

외부 URL을 서버에서 읽는 API를 만들 경우 사용자가 내부망 주소를 호출하게 만들 수 있습니다.  
예:

```text
http://localhost:8080/admin
http://127.0.0.1:3306
http://169.254.169.254/
http://10.x.x.x/
http://192.168.x.x/
```

따라서 실무에서는 아래 검증이 필요합니다.

|방어 항목|설명|
|---|---|
|URL Scheme 제한|`http`, `https`만 허용|
|사설 IP 차단|`127.0.0.1`, `10.*`, `172.16~31.*`, `192.168.*` 차단|
|localhost 차단|`localhost`, 내부 도메인 차단|
|Redirect 후 주소 재검증|redirect 된 최종 URL도 검증|
|응답 크기 제한|대용량 HTML 다운로드 방지|
|Timeout 설정|연결/읽기 timeout 필수|
|allowlist 방식|가능하면 허용 도메인만 수집|
